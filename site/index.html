Why Husky

Everything a note app should be. Nothing it shouldn't.

Fast, native, and built around one promise — your writing is plain Markdown, and you can take it anywhere.

✍️

Markdown at heart

Every note's body is plain CommonMark. Write with live, inline-rendered formatting powered by a real native text engine — no web view, no lag.

☁️

Sync that just works

Built on the same record-level CloudKit model as the apps you trust. Silent, account-scoped, conflict-aware. Works fully offline too.

🎨

Beautiful themes

Theming is a core feature, not a setting buried away. Ship with Blue Husky, Husky Day, and more — or craft your own palette and type.

🗂️

Tags & smart lists

Drop #inline tags anywhere. Husky builds smart lists automatically — Pinned, Today, Untagged, per-tag — with zero setup.

🔍

Instant search

A full-text index keeps search snappy at thousands of notes. Compose tag filters and text — #work invoice — and find it now.

🔓

Your data is never trapped

One toggle mirrors every note to real .md files with YAML frontmatter — drop them straight into Obsidian. Open data, guaranteed.

The editor

A writing surface that feels effortless

TextKit 2 powers live, themed rendering as you type. Headings, quotes, lists, code and inline tags style themselves inline — while the underlying file stays clean, portable Markdown.

  • Live inline Markdown — no preview pane to flip to
  • Native typography, smooth selection, real keyboard support
  • Code blocks, checklists, tables, footnotes
  • Distraction-free focus mode

Sync & privacy

Everywhere you write, instantly in step

Notes live in your own private iCloud database — encrypted in transit and at rest, scoped to your Apple ID. There's no Husky server and no account to create. We never see a word you write.

  • Record-level sync with automatic conflict handling
  • Offline-first — keep working, it catches up
  • Optional Face ID / Touch ID app lock
  • No tracking, no ads, no analytics on your content
